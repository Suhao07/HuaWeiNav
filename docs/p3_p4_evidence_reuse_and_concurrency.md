# P3/P4：证据复用与候选请求并发

## 实现边界

候选识别使用同一个观察周期：主线程冻结请求、查询缓存；线程池请求模型；全部必要请求成功后主线程按候选原顺序提交。默认 `STRIVE_VLM_WORKERS=2`，设为 1 可使用同一路径串行执行。新增复用由 `STRIVE_EVIDENCE_REUSE=1` 启用；设为 0 关闭本轮候选/最终视觉复用，既有类别词概念匹配缓存保持不变。

精确缓存键为 $K=H(\text{provider},\text{endpoint},\text{model},\text{thinking},\text{prompt},\text{schema},\text{images})$。候选缓存额外包含目标标签规范化的输入与配置。全图上下文和裁剪均参与哈希。缓存损坏明确报错。

实例复用沿用双向 10cm 点覆盖至少 80%、唯一对应，以及面积/清晰度改善 25% 触发取证的现有规则；新增源观察、配置和关联后地图支撑指纹。同 UID 支撑或标签变化使记录失效。严格点云哈希可能降低命中率，本轮先验证正确性。缓存复用不追加模型置信度。完整扫描与局部扫描共享入口。

当前批量概念匹配只输入类别词，保留其 instruction/concept/label 缓存；单对象视觉匹配已有实际视觉字段依赖，本轮保持。未新建概念判断模块。

最终验证只复用完全相同任务版本、观察身份、模型输入与相关依赖的视觉判断。每次重新组合当前物理条件：$F_t=V(E,r)\land G_t\land Complete(q_t)$。图像变化请求模型；缓存保留原图像证据身份，任务 reducer 仍按实例 UID 去重计数。候选标签复用不授权 STOP。

线程不读写 mapper；每个工作项使用已准备请求与固定目标规范化参数。缓存和地图由主线程写入。调用日志的编号与计数用短锁保护。一次 JSON/schema 重试继续生效；重试失败传播异常，保存响应，无替代标签。

## 验证

固定输入测试覆盖：全图变化、缓存损坏、实例支撑替换、多实例歧义、返回乱序、错误传播、日志编号并发唯一，以及视觉判断命中后重新检查当前运动条件。

实测四组共用冻结源码与关闭 thinking：A（新增复用关/1线程）、B（P3/1线程）、C（新增复用关/2线程）、D（P3/2线程）。选择相同 HM3D 索引 5 sofa、7 toilet、9 chair。该实验比较当前框架的开关组合，不重跑或改写历史原始 baseline。逐例保存命令、身份、首帧、模型请求、等待时间和 Habitat 指标；原始错误 chair 同时作为误接受风险检查。单次随机响应不足以证明普遍收益。
