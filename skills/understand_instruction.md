# Instruction Understanding

The complete original instruction has final semantic authority on every decision and final verification. Structured targets, constraints and search priors are revisable aids, never an exhaustive substitute for the original wording. Omitted clauses remain binding; do not redefine a requirement to fit a convenient observation.

Read the original instruction before selecting a search target. Preserve the named destination and every explicit attribute, relation, prohibition, count and order. For a need, distinguish the intended activity, the material being acted on, and the resource that enables the activity; treat possible facilities as hypotheses, not additional requirements.

Compare the current interpretation with the original wording, then inspect the supplied observation and verification feedback. Identify what is still unknown and choose an available search or observation action that can resolve it.

Use the returned evidence to choose the next step:

- Missing evidence or an unseen reference object: retain the requirement and obtain another observation; do not reject the target merely because the reference is missing.
- Contradicted instance or relation: try another candidate or object pair. One failed instance does not invalidate the underlying need.
- Unhelpful retrieval phrases: revise the search terms, then inspect the resulting candidates. Retrieval terms do not prove identity or functionality.
- An interpretation that omits or invents a requirement: propose a correction justified by the original wording, not by whichever objects are easiest to find.

Read the revision result before acting. After adoption, query the updated task and candidates and select a new action; after rejection or uncertainty, retain the current task and use the feedback to choose a different supported hypothesis or observation. Do not repeat an unchanged proposal or failed view without new justification.

Verify the actual instance against the original request. Category-level typical use, a revised interpretation and arrival are not completion evidence; use the active-observation and completion checks before finishing.
